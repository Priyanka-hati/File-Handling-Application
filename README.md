# File Handling Application in Python

This project is a menu-driven Python application that demonstrates
different file handling operations using Object-Oriented Programming.

## Features

1. Create / Write File
2. Read File
3. Append to File
4. Search in File
5. Count Lines
6. Copy File
7. Rename File
8. Delete File
9. Exit

## Technologies Used

- Python
- Jupyter Notebook
- Object-Oriented Programming
- os module
- shutil module

## File Operations

The application demonstrates Python file operations such as:

- open()
- read()
- write()
- append
- rename
- copy
- delete

## How to Run

Open the Jupyter Notebook:

File_Handling_Application.ipynb

Run the cells in order and execute the final application cell.
